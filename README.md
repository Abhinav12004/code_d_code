# Code_d_Code Website

Welcome to the official repository for the **Code_d_Code Coding Society** website!

## Overview

This project is the website for the Code_d_Code Coding Society, a student community passionate about coding, ethical hacking, web development, and all things tech. The website provides information about our club, events, projects, team, and more.

## Features

- **Responsive Design:** Works seamlessly on desktops, tablets, and smartphones.
- **About Us:** Learn about our mission, activities, and history.
- **Projects:** Explore the projects developed by our members.
- **Events:** Stay updated with upcoming and past events.
- **Gallery:** View photos from our activities.
- **Executive Team:** Meet the coordinators and secretaries.
- **Footer & Navigation:** Easy navigation and contact links.

## Technologies Used

- HTML5
- CSS3 (with Bootstrap 5)
- JavaScript (for interactivity)
- [Bootstrap CDN](https://getbootstrap.com/)

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/your-username/code_d_code.git
   ```
2. **Navigate to the project folder:**
   ```sh
   cd code_d_code
   ```
3. **Open `index.html` or any page in your browser.**

> No build steps required. All files are static and ready to use.
